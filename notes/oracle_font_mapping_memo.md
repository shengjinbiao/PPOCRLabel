## 结论

`C:\Users\sheng\Downloads\甲骨字体库\甲骨文字体库.ttf` 与《殷契文渊》字形库编码基本可以对应。

这款字体内部名称为 `AYJGW(乔老师甲骨字替换)`，使用 `U+60000` 起的一段未分配 Unicode 码位来显示甲骨文字形。例如：

```text
U+60000 -> 字体显示甲骨字形 -> 殷契文渊释字：人
```

字体本身只负责把码位显示成甲骨字形；现代汉字释字关系不可靠地存于字体文件本身，而应来自《殷契文渊》字形库数据库中的 `FTZ` / `JTZ` 字段。

## 使用原则

推荐路线：

```text
OCR 识别输出字库编码或字库字符 -> 查映射表 -> 得到现代释字
```

不建议直接把甲骨文字体 cmap 改到现代 Unicode 码位。例如不应简单把甲骨文“人”的字形映射到 `U+4EBA`，因为多个甲骨字形可能同释为一个现代汉字，直接改码会丢失异体关系，也会和普通现代汉字显示冲突。

正确分工：

```text
字体：显示甲骨字形
映射表：解释该甲骨字形对应的现代释字
```
